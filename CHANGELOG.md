# CHANGELOG - Course Drift Detector

## v1.0.0 - 2024-11-15
### Added
- Initial release of the Course Drift Detector plugin.
- Core functionality for tracking structural and configuration course changes.
- Admin dashboard to display courses with the highest drift.
- Per-course detail page showing a timeline of detected changes.
- Scheduled task for periodic course analysis.
- Configurable settings for drift sensitivity and analysis time window.
- Capabilities for managing access to reports.
- Comprehensive security measures (sesskey, clean_param, capability checks, DB placeholders).
- Developer attribution and documentation.
